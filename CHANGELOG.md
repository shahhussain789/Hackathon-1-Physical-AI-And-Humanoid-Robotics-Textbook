## Versioning Guide

**Format**: MAJOR.MINOR.PATCH

- **MAJOR**: Curriculum restructuring, removal of modules, breaking changes
- **MINOR**: New modules, significant content additions, new features
- **PATCH**: Corrections, clarifications, minor updates, bug fixes

### Examples

- `2.0.0`: Restructured curriculum to 5 modules instead of 4
- `1.1.0`: Added Module 5 on Advanced Locomotion
- `1.0.1`: Fixed typos in Module 1, updated broken links

## Release Schedule

- **Major releases**: Annually (aligned with academic year)
- **Minor releases**: Quarterly (new modules or significant additions)
- **Patch releases**: As needed (corrections, updates)
