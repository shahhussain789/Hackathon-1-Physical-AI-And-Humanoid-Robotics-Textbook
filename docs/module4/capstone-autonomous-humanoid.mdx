# Capstone Project: The Autonomous Humanoid

## Introduction

**This is it—the culmination of all four modules!**

You'll build a fully autonomous humanoid that:
1. **Listens** to voice commands (Whisper)
2. **Reasons** about tasks (LLM planning)
3. **Sees** the world (computer vision)
4. **Navigates** autonomously (Nav2 + VSLAM)
5. **Manipulates** objects (MoveIt 2)

**Scenario**: "Find the red cup on the table and bring it to me"

Let's build it step by step.

## Phase 3: Complete VLA System

### Main Controller Node

**`autonomous_humanoid.py`**:
```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from rclpy.action import ActionClient
from std_msgs.msg import String
from nav2_msgs.action import NavigateToPose
from moveit_msgs.action import MoveGroup
import json

class AutonomousHumanoid(Node):
    """Complete VLA system integrating all modules."""

    def __init__(self):
        super().__init__('autonomous_humanoid')

        # Voice input (from Whisper node)
        self.voice_sub = self.create_subscription(
            String, '/voice_commands', self.voice_callback, 10
        )

        # Action clients
        self.nav_client = ActionClient(self, NavigateToPose, 'navigate_to_pose')
        self.moveit_client = ActionClient(self, MoveGroup, '/move_action')

        # Modules
        from llm_planner import GPT4VisionPlanner
        from perception import VisionLanguageGrounder

        self.planner = GPT4VisionPlanner()
        self.grounder = VisionLanguageGrounder()

        # State
        self.current_plan = None
        self.detected_objects = {}

        self.get_logger().info("Autonomous Humanoid online!")

    def voice_callback(self, msg):
        """Process voice command."""
        command = msg.data
        self.get_logger().info(f"Voice command: {command}")

        # Execute complete pipeline
        self.execute_task(command)

    def execute_task(self, command):
        """Main VLA pipeline."""

        # Step 1: Get current camera view
        scene_image = self.capture_scene_image()

        # Step 2: LLM planning (with vision context)
        plan = self.planner.plan_from_image(command, scene_image)
        self.get_logger().info(f"Plan: {json.dumps(plan, indent=2)}")

        # Step 3: Execute plan
        self.execute_plan(plan)

    def execute_plan(self, plan):
        """Execute action sequence."""

        for i, action in enumerate(plan):
            self.get_logger().info(f"Step {i+1}/{len(plan)}: {action}")

            # Safety check
            if not self.validate_action_safety(action):
                self.get_logger().error("Unsafe action, aborting")
                return

            # Execute based on action type
            action_type = action["action"]

            if action_type == "navigate_to":
                success = self.execute_navigation(action["params"])
            elif action_type == "detect_object":
                success = self.execute_detection(action["params"])
            elif action_type == "grasp_object":
                success = self.execute_grasp(action["params"])
            elif action_type == "release_object":
                success = self.execute_release()
            elif action_type == "say":
                success = self.execute_speech(action["params"])
            else:
                self.get_logger().warn(f"Unknown action: {action_type}")
                success = False

            # Verify success
            if not success:
                self.get_logger().error(f"Action failed: {action}")
                # Attempt recovery
                self.attempt_recovery(plan[i:])
                return

        self.get_logger().info("Task completed successfully!")

    def execute_navigation(self, params):
        """Navigate to location."""
        location = params["location"]
        self.get_logger().info(f"Navigating to {location}")

        # Get coordinates (from map or predefined)
        target_pose = self.get_location_pose(location)

        # Send Nav2 goal
        goal = NavigateToPose.Goal()
        goal.pose = target_pose

        future = self.nav_client.send_goal_async(goal)
        rclpy.spin_until_future_complete(self, future)

        goal_handle = future.result()
        if not goal_handle.accepted:
            return False

        result_future = goal_handle.get_result_async()
        rclpy.spin_until_future_complete(self, result_future)

        return True

    def execute_detection(self, params):
        """Detect and ground object."""
        object_name = params["name"]
        self.get_logger().info(f"Detecting: {object_name}")

        # Capture current view
        scene_image = self.capture_scene_image()

        # Ground using CLIP
        result, msg = self.grounder.ground_object(scene_image, object_name)

        if result:
            self.detected_objects[object_name] = result
            self.get_logger().info(f"Found {object_name}: {msg}")
            return True
        else:
            return False

    def execute_grasp(self, params):
        """Grasp detected object."""
        object_id = params.get("object_id") or params.get("name")
        self.get_logger().info(f"Grasping: {object_id}")

        # Get 3D position from detection
        if object_id not in self.detected_objects:
            self.get_logger().error(f"Object {object_id} not detected")
            return False

        bbox = self.detected_objects[object_id]["bbox"]
        depth_image = self.get_depth_image()
        position_3d = self.bbox_to_3d(bbox, depth_image)

        # Plan grasp with MoveIt 2
        success = self.plan_and_execute_grasp(position_3d)
        return success
```

## Phase 4: Testing & Validation

### Test Scenarios

**Test 1: Simple Fetch**
```
Command: "Bring me the red cup"
Expected:
1. Navigate to table
2. Detect red cup (not blue cup!)
3. Grasp cup
4. Navigate to user
5. Release cup
```

**Test 2: Object Selection**
```
Command: "Find the cup on the left side of the table"
Expected:
1. Navigate to table
2. Detect all cups
3. Select leftmost cup (spatial reasoning)
4. Confirm with user
```

**Test 3: Multi-Step Task**
```
Command: "Clean the table by putting all objects in the box"
Expected:
1. Navigate to table
2. Detect all objects
3. For each object:
   a. Grasp
   b. Navigate to box
   c. Release
4. Confirm completion
```

### Evaluation Metrics

| Metric | Target | Measurement |
|--------|--------|-------------|
| **Speech Recognition** | &gt;95% accuracy | Word Error Rate (WER) |
| **Task Completion** | &gt;80% success | 10 trials per task |
| **Navigation** | &lt;10cm error | Distance to goal |
| **Object Detection** | &gt;90% precision | True positives |
| **Grasp Success** | &gt;75% | Successful grasps / attempts |
| **End-to-End Latency** | &lt;10 seconds | Command → action start |

### Debug Checklist

If something fails:

- [ ] **Speech**: Check Whisper output, test with known phrases
- [ ] **Planning**: Print LLM responses, verify JSON format
- [ ] **Vision**: Visualize detections, check CLIP scores
- [ ] **Navigation**: View Nav2 costmap, check VSLAM localization
- [ ] **Manipulation**: Test MoveIt 2 IK, verify gripper control
- [ ] **Safety**: Ensure all safety monitors active
