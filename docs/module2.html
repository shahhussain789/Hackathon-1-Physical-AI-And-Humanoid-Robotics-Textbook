Module 2: The Digital Twin (Gazebo & Unity)

Why Simulate Before You Build​

Every humanoid robot that walks, grasps, or navigates in the real world was first tested thousands of times in simulation. Breaking a $50,000 robot because your controller had a sign error is not an option. Simulation is not a shortcut -- it is an essential engineering discipline.

Welcome to Module 2, where you will build digital twins of robots: virtual replicas that behave like their physical counterparts, complete with realistic physics, sensors, and environmental interactions.

What You'll Learn​

This module takes you from zero simulation experience to building complete virtual robotics environments. You will master two industry-standard tools:

  • Gazebo: The open-source physics simulator used by the majority of ROS-based robotics teams worldwide
  • Unity: A high-fidelity rendering engine increasingly adopted for human-robot interaction research and synthetic data generation

Learning Objectives​

By the end of this module, you will be able to:

  • Set up Gazebo and understand its architecture, physics engines, and world-building tools
  • Build robot models using URDF and SDF description formats with proper collision and visual geometry
  • Simulate sensors including LiDAR, depth cameras, IMUs, and standard cameras with realistic noise models
  • Integrate Gazebo with ROS 2 to create complete simulation pipelines with launch files and topic bridges
  • Use Unity for photorealistic robot visualization and human-robot interaction scenarios
  • Compare simulation tools and choose the right one for different robotics tasks

Module Structure​

Chapter 1: Gazebo Simulation Fundamentals​

Get Gazebo up and running and understand what happens under the hood. Learn about physics engines, world files, and how gravity, friction, and collisions are simulated.

Key Concepts: Gazebo architecture, physics engines (ODE, Bullet, DART), world files, simulation step

Chapter 2: Robot Models -- URDF & SDF​

Build the virtual body of your robot. Learn two industry-standard formats for describing robot geometry, joints, materials, and physical properties.

Key Concepts: URDF links and joints, SDF models, collision vs. visual geometry, meshes, inertial properties

Chapter 3: Simulating Sensors​

Give your robot eyes, ears, and a sense of balance. Simulate the full sensor suite that real humanoids carry, with realistic noise and physics.

Key Concepts: LiDAR (2D/3D), depth cameras (RGB-D), IMUs, camera models, sensor plugins, noise models

Chapter 4: ROS 2 + Gazebo Integration​

Connect your simulated robot to the ROS 2 ecosystem. Spawn robots from launch files, send commands via topics, and read sensor data in Python nodes.

Key Concepts: gazebo_ros_pkgs, ros_gz bridge, launch files, topic remapping, simulation pipelines

Chapter 5: Unity for Robot Visualization​

Explore Unity as a complementary tool for photorealistic rendering, synthetic data generation, and human-robot interaction design.

Key Concepts: Unity Robotics Hub, ROS-TCP-Connector, URDF Importer, high-fidelity rendering, HRI scenarios

Prerequisites​

From Module 1​

You should have completed Module 1 and be comfortable with:

  • ROS 2 fundamentals: Nodes, topics, publishers, subscribers
  • Linux command line: Navigation, package management, environment sourcing
  • Python 3: Basic scripting, working with libraries

Software Requirements​

  • OS: Ubuntu 22.04 (recommended) or WSL2 on Windows
  • ROS 2: Humble Hawksbill installed and sourced
  • Gazebo: Harmonic (recommended) or Classic 11
  • Python: 3.10+ with NumPy
  • Unity: 2022.3 LTS (for Chapter 5 only)
WSL2 Users

If you are on Windows, WSL2 with Ubuntu 22.04 works well for Gazebo and ROS 2. Unity runs natively on Windows and communicates with ROS 2 in WSL2 over the network. See Appendix A for WSL2 setup instructions.

Hardware​

  • Minimum: 8 GB RAM, modern CPU, integrated graphics (Gazebo only)
  • Recommended: 16 GB RAM, dedicated GPU (required for Unity, helpful for Gazebo rendering)

Module Philosophy: Build the Twin First​

In Physical AI development, the standard workflow is:

  1. Model the robot in simulation (this module)
  2. Develop perception and control algorithms against the simulated robot (Modules 3-4)
  3. Transfer validated algorithms to real hardware (Module 4 capstone)

This module focuses entirely on step 1. Every chapter is hands-on: you will write world files, build robot descriptions, configure sensors, and wire everything into ROS 2. By the end, you will have a fully functional simulated humanoid that you can command, observe, and test -- all without risking real hardware.

Digital Twin Definition

A digital twin is a virtual replica of a physical system that mirrors its geometry, physics, sensors, and behavior in real time. In robotics, digital twins enable rapid prototyping, safe testing of dangerous scenarios, and generation of synthetic training data for AI.

How to Navigate This Module​

Sequential Path (Recommended)​

Follow Chapters 1 through 5 in order. Each chapter builds on the previous:

  1. Gazebo fundamentals (the simulator)
  2. Robot models (the robot body)
  3. Sensor simulation (the robot's senses)
  4. ROS 2 integration (the communication layer)
  5. Unity visualization (advanced rendering)

Practical Fast Track​

If you want to get a robot running in simulation as quickly as possible:

  1. Start with Chapter 1 (install Gazebo, run a demo world)
  2. Jump to Chapter 4 (spawn a pre-built robot via ROS 2)
  3. Return to Chapters 2-3 to understand and customize what you spawned

Reference Use​

Each chapter is self-contained enough to serve as a reference. The code examples are complete and can be copied directly into your workspace.

What's Next?​

After Module 2, you will have a fully simulated robot with working sensors and ROS 2 connectivity. You will use this simulation environment extensively in:

  • Module 3: Perception and Sensor Fusion -- process the simulated sensor data you learned to generate here
  • Module 4: AI for Locomotion and Manipulation -- train and test control policies in your Gazebo environment
