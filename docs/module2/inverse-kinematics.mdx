# Inverse Kinematics: Solving for Desired Poses

## Introduction

You want a robot to pick up a coffee mug at position (x=0.3m, y=0.2m, z=0.5m). **Question**: What joint angles achieve this?

This is the **inverse kinematics (IK)** problem—arguably the most important problem in robot control.

## The Inverse Kinematics Problem

:::tip Definition
**Inverse Kinematics (IK)**: Given a desired end-effector pose (position and orientation), find the joint angles θ that achieve it.
:::

### Forward vs. Inverse

| Problem | Input | Output | Difficulty |
|---------|-------|--------|-----------|
| **Forward Kinematics** | Joint angles θ | End-effector pose (x, y, z, R) | Easy (just matrix multiplication) |
| **Inverse Kinematics** | Desired pose (x, y, z, R) | Joint angles θ | Hard (non-linear, multiple solutions) |

### Why IK is Hard

1. **Non-linear equations**: Involves trigonometric functions
2. **Multiple solutions**: A 2-link arm can reach the same point with "elbow up" or "elbow down"
3. **No solution**: Desired pose may be outside workspace (unreachable)
4. **Infinite solutions**: 7-DoF arm (redundant) has infinite ways to reach same pose

## Analytical IK (Geometric Solutions)

### When Can We Use Analytical IK?

**Requirements**:
- Simple robot geometry (low DoF, specific configurations)
- Closed-form solution exists

**Advantages**:
- Fast (no iteration)
- Always gives same solution for same input
- No convergence issues

**Disadvantages**:
- Only works for specific robot designs
- Difficult to derive for complex robots

### Example: 2-Link Planar Arm

**Given**: Desired end-effector position (x_d, y_d)

**Find**: Joint angles (θ₁, θ₂)

**Geometric Solution**:

Using the law of cosines:
```
c₂ = (x_d² + y_d² - L₁² - L₂²) / (2·L₁·L₂)

θ₂ = ± arccos(c₂)  (two solutions: elbow up/down)

θ₁ = atan2(y_d, x_d) - atan2(L₂·sin(θ₂), L₁ + L₂·cos(θ₂))
```

**Python Implementation**:
```python
import numpy as np

def inverse_kinematics_2link(x_d, y_d, L1=1.0, L2=0.8, elbow_up=True):
    """Analytical IK for 2-link planar arm."""

    # Check if target is reachable
    dist = np.sqrt(x_d**2 + y_d**2)
    if dist > (L1 + L2) or dist < abs(L1 - L2):
        raise ValueError(f"Target ({x_d}, {y_d}) is unreachable!")

    # Compute θ2 using law of cosines
    c2 = (x_d**2 + y_d**2 - L1**2 - L2**2) / (2 * L1 * L2)

    # Clamp to [-1, 1] to avoid numerical errors in arccos
    c2 = np.clip(c2, -1, 1)

    # Two solutions for θ2
    theta2 = np.arccos(c2) if elbow_up else -np.arccos(c2)

    # Compute θ1
    k1 = L1 + L2 * np.cos(theta2)
    k2 = L2 * np.sin(theta2)
    theta1 = np.arctan2(y_d, x_d) - np.arctan2(k2, k1)

    return theta1, theta2

# Example usage
x_d, y_d = 1.2, 0.8
theta1, theta2 = inverse_kinematics_2link(x_d, y_d)
print(f"θ1 = {np.rad2deg(theta1):.2f}°, θ2 = {np.rad2deg(theta2):.2f}°")
```

**Output**: `θ1 = 23.58°, θ2 = 76.37°`

## Numerical IK (Iterative Methods)

### Jacobian-Based IK

**Idea**: Use the Jacobian to iteratively adjust joint angles.

**Recall from Chapter 1**:
```
ẋ = J(θ) · θ̇
```

Rearranging:
```
θ̇ = J⁻¹(θ) · ẋ
```

**Algorithm** (Jacobian Inverse Method):
```
1. Initialize θ = θ₀ (initial guess)
2. Repeat:
   a. Compute current end-effector pose: x = FK(θ)
   b. Compute error: Δx = x_desired - x
   c. Compute Jacobian: J = Jacobian(θ)
   d. Update joints: θ = θ + α · J⁻¹ · Δx
3. Until ||Δx|| < ε (converged)
```

Where α is a step size (e.g., 0.1).

**Python Implementation**:
```python
def jacobian_2link(theta1, theta2, L1=1.0, L2=0.8):
    """Analytical Jacobian for 2-link arm."""
    s1, c1 = np.sin(theta1), np.cos(theta1)
    s12, c12 = np.sin(theta1+theta2), np.cos(theta1+theta2)

    J = np.array([
        [-L1*s1 - L2*s12, -L2*s12],
        [ L1*c1 + L2*c12,  L2*c12]
    ])
    return J

def ik_jacobian(x_d, y_d, L1=1.0, L2=0.8, theta_init=None, max_iter=100):
    """Numerical IK using Jacobian inverse."""
    if theta_init is None:
        theta_init = np.array([0.0, 0.0])

    theta = theta_init.copy()
    alpha = 0.1  # Step size

    for i in range(max_iter):
        # Forward kinematics
        x, y, _ = forward_kinematics_2link(theta[0], theta[1], L1, L2)

        # Compute error
        error = np.array([x_d - x, y_d - y])

        # Check convergence
        if np.linalg.norm(error) < 1e-4:
            print(f"Converged in {i} iterations")
            return theta

        # Compute Jacobian
        J = jacobian_2link(theta[0], theta[1], L1, L2)

        # Update (with damped least squares to avoid singularities)
        lambda_damping = 0.01
        theta += alpha * np.linalg.inv(J.T @ J + lambda_damping * np.eye(2)) @ J.T @ error

    raise RuntimeError("IK did not converge")

# Example
theta_result = ik_jacobian(1.2, 0.8)
print(f"Solution: θ1={np.rad2deg(theta_result[0]):.2f}°, θ2={np.rad2deg(theta_result[1]):.2f}°")
```

### Damped Least Squares (DLS)

**Problem**: J⁻¹ becomes unstable near singularities (where det(J) ≈ 0).

**Solution**: Add damping term:
```
θ̇ = (JᵀJ + λI)⁻¹ Jᵀ Δx
```

Where λ is a small damping factor (e.g., 0.01).

## Handling Multiple Solutions

### Solution Space

For a 2-link arm:
- **2 solutions**: Elbow up, elbow down
- Choose based on criteria:
  - Closer to current configuration (minimize joint motion)
  - Avoids joint limits
  - Avoids obstacles

**Selection Strategy**:
```python
# Compute both solutions
theta_up = ik_analytical(x_d, y_d, elbow_up=True)
theta_down = ik_analytical(x_d, y_d, elbow_up=False)

# Choose closest to current configuration
dist_up = np.linalg.norm(theta_up - theta_current)
dist_down = np.linalg.norm(theta_down - theta_current)

theta_best = theta_up if dist_up < dist_down else theta_down
```

## Singularities

### What is a Singularity?

**Definition**: A configuration where the robot loses a degree of freedom.

**Example** (2-link arm):
- **Fully extended**: θ₂ = 0 (arm is straight)
- **Fully retracted**: θ₂ = ±180° (links overlap)

At singularities:
- det(J) = 0
- J is not invertible
- Small end-effector motion requires infinite joint velocity

### Detecting Singularities

```python
def is_singular(J, threshold=1e-3):
    """Check if Jacobian is singular."""
    return abs(np.linalg.det(J)) < threshold
```

### Avoiding Singularities

1. **Damped Least Squares**: Adds numerical stability
2. **Joint limits**: Constrain θ to avoid extreme configurations
3. **Path planning**: Route around singular configurations

## Optimization-Based IK

### Formulation as Optimization

**Objective**: Minimize error between desired and achieved pose.

**Cost Function**:
```
minimize: ||FK(θ) - x_desired||²
subject to: θ_min ≤ θ ≤ θ_max (joint limits)
```

**Tools**:
- **SciPy optimize**: `scipy.optimize.minimize`
- **IPOPT**: Interior Point Optimizer (faster for large problems)
- **CasADi**: Automatic differentiation for gradients

**Python Example** (using SciPy):
```python
from scipy.optimize import minimize

def ik_optimization(x_d, y_d, L1=1.0, L2=0.8):
    def cost(theta):
        x, y, _ = forward_kinematics_2link(theta[0], theta[1], L1, L2)
        return (x - x_d)**2 + (y - y_d)**2

    # Initial guess
    theta_init = np.array([0.0, 0.0])

    # Joint limits
    bounds = [(-np.pi, np.pi), (-np.pi, np.pi)]

    result = minimize(cost, theta_init, bounds=bounds, method='SLSQP')

    if result.success:
        return result.x
    else:
        raise RuntimeError("Optimization failed")

# Example
theta = ik_optimization(1.2, 0.8)
print(f"θ1={np.rad2deg(theta[0]):.2f}°, θ2={np.rad2deg(theta[1]):.2f}°")
```

## IK for Humanoid Arms (7-DoF)

### Redundancy

A 7-DoF arm has **redundancy** (more joints than needed for 6-DoF pose).

**Implication**: Infinite solutions for a given end-effector pose.

**Benefit**: Can optimize for secondary objectives:
- Minimize joint motion
- Avoid obstacles
- Stay away from joint limits

### Null-Space Optimization

**Idea**: Move in null space of Jacobian (doesn't affect end-effector).

**Formulation**:
```
θ̇ = J⁺ ẋ_desired + (I - J⁺J) θ̇₀

where:
- J⁺ = pseudoinverse of J
- (I - J⁺J) = null-space projector
- θ̇₀ = secondary objective (e.g., move toward mid-range of joints)
```

**Example Secondary Objectives**:
- Maximize manipulability (stay away from singularities)
- Minimize energy (prefer configurations closer to rest pose)
- Avoid obstacles (repulsive potential fields)

## IK in ROS 2

### KDL (Kinematics and Dynamics Library)

ROS 2 provides `kdl_parser` and `kdl` for IK:

```python
from kdl_parser_py.urdf import treeFromFile
from PyKDL import ChainIkSolverPos_LMA

# Load robot from URDF
tree = treeFromFile("robot.urdf")
chain = tree.getChain("base_link", "end_effector")

# Create IK solver (Levenberg-Marquardt)
ik_solver = ChainIkSolverPos_LMA(chain)

# Solve IK
desired_pose = PyKDL.Frame(PyKDL.Vector(0.3, 0.2, 0.5))
joint_angles = PyKDL.JntArray(chain.getNrOfJoints())

result = ik_solver.CartToJnt(initial_guess, desired_pose, joint_angles)
```

### MoveIt 2 (Motion Planning Framework)

**MoveIt 2** provides high-level IK and motion planning:

```python
from moveit_msgs.srv import GetPositionIK

ik_request = GetPositionIK.Request()

ik_request.ik_request.pose_stamped.pose.position.x = 0.3
ik_request.ik_request.pose_stamped.pose.position.y = 0.2
ik_request.ik_request.pose_stamped.pose.position.z = 0.5

response = ik_client.call(ik_request)
joint_angles = response.solution.joint_state.position
```

## Summary

**Inverse Kinematics** solves for joint angles given desired end-effector pose:

- **Analytical IK**: Closed-form solutions (fast but limited to simple robots)
- **Numerical IK**: Jacobian-based iteration (general but may fail at singularities)
- **Optimization IK**: Formulate as minimization problem (handles constraints)
- **Redundancy**: 7-DoF arms have infinite solutions → null-space optimization
- **ROS 2 tools**: KDL, MoveIt 2 provide production-ready IK solvers
