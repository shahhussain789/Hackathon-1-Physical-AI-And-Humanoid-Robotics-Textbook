# Simulation Environments: Gazebo and NVIDIA Isaac Setup

## Why Simulate?

**Testing on real robots is**:
- Expensive (risk of damage)
- Slow (real-time only)
- Limited (one robot at a time)

**Simulation enables**:
- Safe testing (no hardware damage)
- Fast iteration (faster than real-time)
- Parallel experiments (run 100 robots simultaneously)
- Reproducibility (exact same conditions)

## Gazebo Classic Setup

### Installation (Ubuntu 22.04)

```bash
# Install Gazebo Classic 11
sudo apt update
sudo apt install gazebo11 libgazebo11-dev

# Install ROS 2 Gazebo packages
sudo apt install ros-humble-gazebo-ros-pkgs
```

### First Simulation

```bash
# Launch Gazebo with empty world
gazebo

# Or with ROS 2 integration
ros2 launch gazebo_ros gazebo.launch.py
```

**What You Should See**: 3D environment with ground plane, lighting, and physics running.

### Creating a Robot Model (URDF)

**URDF** (Unified Robot Description Format) defines robot structure.

**Simple 2-Link Arm** (`robot.urdf`):
```xml
<?xml version="1.0"?>
<robot name="two_link_arm">
  <!-- Base Link -->
  <link name="base_link">
    <visual>
      <geometry>
        <box size="0.1 0.1 0.1"/>
      </geometry>
      <material name="blue">
        <color rgba="0 0 1 1"/>
      </material>
    </visual>
    <collision>
      <geometry>
        <box size="0.1 0.1 0.1"/>
      </geometry>
    </collision>
    <inertial>
      <mass value="1"/>
      <inertia ixx="0.01" ixy="0" ixz="0" iyy="0.01" iyz="0" izz="0.01"/>
    </inertial>
  </link>

  <!-- Link 1 -->
  <link name="link1">
    <visual>
      <origin xyz="0 0 0.5" rpy="0 0 0"/>
      <geometry>
        <cylinder radius="0.05" length="1.0"/>
      </geometry>
      <material name="red">
        <color rgba="1 0 0 1"/>
      </material>
    </visual>
    <collision>
      <origin xyz="0 0 0.5" rpy="0 0 0"/>
      <geometry>
        <cylinder radius="0.05" length="1.0"/>
      </geometry>
    </collision>
    <inertial>
      <origin xyz="0 0 0.5" rpy="0 0 0"/>
      <mass value="0.5"/>
      <inertia ixx="0.04" ixy="0" ixz="0" iyy="0.04" iyz="0" izz="0.001"/>
    </inertial>
  </link>

  <!-- Joint 1 (Shoulder) -->
  <joint name="shoulder_joint" type="revolute">
    <parent link="base_link"/>
    <child link="link1"/>
    <origin xyz="0 0 0.1" rpy="0 0 0"/>
    <axis xyz="0 1 0"/>
    <limit lower="-3.14" upper="3.14" effort="10" velocity="1"/>
  </joint>

  <!-- Add Gazebo plugin for ROS 2 control -->
  <gazebo>
    <plugin name="gazebo_ros2_control" filename="libgazebo_ros2_control.so"/>
  </gazebo>
</robot>
```

### Spawning Robot in Gazebo

```bash
# Method 1: Command line
ros2 run gazebo_ros spawn_entity.py -entity my_robot -file robot.urdf

# Method 2: Launch file
ros2 launch my_robot spawn_robot.launch.py
```

### Controlling the Robot

**Publish Joint Commands**:
```python
import rclpy
from sensor_msgs.msg import JointState

node = rclpy.create_node('joint_commander')
pub = node.create_publisher(JointState, '/joint_states', 10)

msg = JointState()
msg.name = ['shoulder_joint']
msg.position = [1.57]  # 90 degrees

pub.publish(msg)
```

## NVIDIA Isaac Sim Setup

### System Requirements

- **GPU**: NVIDIA RTX 2000+ (4GB+ VRAM)
- **OS**: Ubuntu 20.04/22.04 or Windows 10/11
- **VRAM**: 8GB+ recommended

### Installation

1. **Download Omniverse Launcher**:
   ```bash
   wget https://install.launcher.omniverse.nvidia.com/installers/omniverse-launcher-linux.AppImage
   chmod +x omniverse-launcher-linux.AppImage
   ./omniverse-launcher-linux.AppImage
   ```

2. **Install Isaac Sim**:
   - Open Omniverse Launcher
   - Navigate to "Exchange" tab
   - Search for "Isaac Sim"
   - Click "Install" (free for educational use)

3. **Launch Isaac Sim**:
   ```bash
   # From Omniverse Launcher or:
   ~/.local/share/ov/pkg/isaac_sim-*/isaac-sim.sh
   ```

### First Scene

**Create Simple Scene**:
1. Launch Isaac Sim
2. Create → Physics → Ground Plane
3. Create → Shapes → Cube (watch it fall with gravity!)
4. Play button (bottom-left) to start physics

### ROS 2 Integration

**Enable ROS 2 Bridge**:
```python
# In Isaac Sim Python console
from omni.isaac.kit import SimulationApp
simulation_app = SimulationApp()

# Enable ROS 2
import omni.isaac.core.utils.extensions as extensions_utils
extensions_utils.enable_extension("omni.isaac.ros2_bridge")

# Now Isaac Sim can publish/subscribe to ROS 2 topics
```

**Example**: Publish camera images to ROS 2:
1. Add camera to scene
2. Add ROS 2 Camera component
3. Configure topic name (e.g., `/camera/image_raw`)
4. Press Play → images published to ROS 2!

### Loading Robot Models

**Import URDF**:
```
File → Import → select robot.urdf
```

**Or programmatically**:
```python
from omni.isaac.urdf import _urdf
urdf_interface = _urdf.acquire_urdf_interface()
urdf_interface.parse_urdf("path/to/robot.urdf", "/World/robot")
```

## Comparing Gazebo vs. Isaac Sim

| Feature | Gazebo Classic | Isaac Sim |
|---------|----------------|-----------|
| **Physics Engine** | ODE, Bullet, DART | PhysX 5 (GPU) |
| **Rendering** | OGRE 1.x | RTX ray tracing |
| **Speed** | Real-time (CPU) | 10-100× faster (GPU) |
| **ROS Integration** | Native | Via bridge |
| **Learning Curve** | Moderate | Steep |
| **Cost** | Free | Free (edu), paid (commercial) |
| **Best For** | General robotics | AI training, photorealistic vision |

**Recommendation**:
- **Start with Gazebo**: Easier to learn, great for kinematics/control
- **Advance to Isaac Sim**: When training RL or vision models

## Physics Engines

### Configuring Physics (Gazebo)

**World file** (`.world`):
```xml
<?xml version="1.0"?>
<sdf version="1.6">
  <world name="default">
    <!-- Set physics engine -->
    <physics name="default_physics" type="ode">
      <max_step_size>0.001</max_step_size>
      <real_time_factor>1.0</real_time_factor>
      <real_time_update_rate>1000</real_time_update_rate>

      <!-- Gravity -->
      <gravity>0 0 -9.81</gravity>

      <!-- ODE solver parameters -->
      <ode>
        <solver>
          <type>quick</type>
          <iters>50</iters>
        </solver>
      </ode>
    </physics>

    <!-- Lighting -->
    <light name="sun" type="directional">
      <pose>0 0 10 0 0 0</pose>
      <diffuse>1 1 1 1</diffuse>
    </light>

    <!-- Ground plane -->
    <include>
      <uri>model://ground_plane</uri>
    </include>
  </world>
</sdf>
```

### Tuning Physics Parameters

**Common Issues**:
- **Robot falls through ground**: Increase solver iterations
- **Joints jittery**: Decrease time step, add damping
- **Simulation slow**: Decrease solver accuracy (trade-off)

## Sensor Simulation

### Adding a Camera (Gazebo)

**In URDF**:
```xml
<gazebo reference="camera_link">
  <sensor name="camera" type="camera">
    <update_rate>30</update_rate>
    <camera>
      <horizontal_fov>1.047</horizontal_fov>
      <image>
        <width>640</width>
        <height>480</height>
      </image>
    </camera>
    <plugin name="camera_plugin" filename="libgazebo_ros_camera.so">
      <ros>
        <namespace>/robot</namespace>
        <remapping>image_raw:=camera/image</remapping>
      </ros>
    </plugin>
  </sensor>
</gazebo>
```

**Subscribe to images** (ROS 2):
```python
from sensor_msgs.msg import Image

def image_callback(msg):
    print(f"Received image: {msg.width}x{msg.height}")

subscriber = node.create_subscription(Image, '/robot/camera/image', image_callback, 10)
```

### LiDAR Sensor

```xml
<gazebo reference="lidar_link">
  <sensor name="lidar" type="ray">
    <ray>
      <scan>
        <horizontal>
          <samples>360</samples>
          <min_angle>-3.14</min_angle>
          <max_angle>3.14</max_angle>
        </horizontal>
      </scan>
      <range>
        <min>0.1</min>
        <max>10.0</max>
      </range>
    </ray>
    <plugin name="lidar_plugin" filename="libgazebo_ros_ray_sensor.so">
      <ros>
        <remapping>~/out:=scan</remapping>
      </ros>
    </plugin>
  </sensor>
</gazebo>
```

## Debugging Simulations

### Visualization Tools

**RViz 2** (ROS Visualization):
```bash
ros2 run rviz2 rviz2
```
- Display robot model
- Show sensor data (camera, LiDAR)
- Visualize TF frames

**Gazebo GUI**:
- View → Contacts (show collision points)
- View → Joints (visualize joint axes)
- View → Transparent (see inside links)

### Common Issues

| Problem | Solution |
|---------|----------|
| Robot falls through ground | Add collision geometry, check physics parameters |
| Joints unstable | Add damping, reduce control gains |
| Simulation too slow | Reduce sensor update rates, simplify meshes |
| ROS 2 topics not appearing | Check plugin configuration, restart Gazebo |
