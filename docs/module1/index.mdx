# Module 1: The Robotic Nervous System (ROS 2)

## Welcome to the Robotic Nervous System

Just as the human nervous system coordinates signals between the brain, spinal cord, and muscles, a robot needs a communication backbone that connects perception, reasoning, and actuation. In modern robotics, that backbone is **ROS 2** — the Robot Operating System 2.

This module takes you from the foundations of Physical AI through the complete ROS 2 stack. By the end, you will be writing Python nodes that publish sensor data, calling services to trigger robot behaviors, and describing humanoid robot bodies in URDF that you can visualize and simulate.

## What You'll Learn

### Learning Objectives

By the end of this module, you will be able to:

- **Define Physical AI** and articulate how embodied intelligence differs from digital-only AI
- **Explain the ROS 2 architecture**, including DDS middleware, QoS policies, and the computation graph
- **Implement nodes, topics, services, and actions** using Python and rclpy
- **Build complete ROS 2 packages** with launch files, parameters, and proper project structure
- **Author URDF models** for humanoid robots and visualize them in RViz2
- **Bridge Python AI agents** to ROS 2 controllers for autonomous robot behavior

## Module Structure

This module spans **Weeks 1 through 5** of the course and is organized into five chapters:

### Chapter 1: Introduction to Physical AI
Lay the conceptual foundation. Learn what Physical AI means, how embodied intelligence works, survey the humanoid robotics landscape, and understand the sensor systems that give robots their senses.

### Chapter 2: ROS 2 Architecture & Core Concepts
Dive into the engineering backbone. Understand why ROS 2 replaced ROS 1, how DDS middleware enables real-time communication, and set up your development environment with workspaces and colcon.

### Chapter 3: Nodes, Topics, Services & Actions
Master the four communication primitives. Build publisher/subscriber pipelines, request/response services, and long-running action servers — the patterns that compose every robot system.

### Chapter 4: Building with Python & rclpy
Go from concepts to code. Create full ROS 2 Python packages, write launch files, manage parameters, and learn the patterns for bridging AI inference engines to robot controllers.

### Chapter 5: URDF for Humanoid Robots
Describe the robot body. Author URDF files that define links, joints, and kinematic chains for a humanoid, then visualize and refine your model using RViz2 and Xacro macros.

## Prerequisites

Before starting this module, you should have:

- **Python programming**: Comfortable writing classes, using pip, and working with libraries like NumPy
- **Basic AI/ML knowledge**: Familiarity with neural networks, inference, and training concepts
- **Linux command line**: Ability to navigate directories, edit files, and run shell commands
- **Ubuntu 22.04** (recommended): ROS 2 Humble Hawksbill runs natively on Ubuntu 22.04 LTS

:::tip No Robotics Experience Required!
This course is designed for software engineers and AI practitioners **without prior robotics experience**. We build every concept from first principles — if you can write a Python class and open a terminal, you are ready.
:::
